{% if lang == 'nl' %}Spelregels{% else %}Ground rules{% endif %}

{% if lang == 'nl' %}Global Union Forum is een plek voor een serieus gesprek, met deelnemers van overal: experts en leken, voorstanders en twijfelaars. Deze vijf spelregels houden het gesprek eerlijk en de moeite waard. Wie bijdraagt, gaat ermee akkoord.{% else %}Global Union Forum is a place for a serious conversation, with participants from everywhere: experts and laypeople, supporters and sceptics. These five ground rules keep the conversation fair and worthwhile. Everyone who contributes agrees to them.{% endif %}

  1. R1

    {% if lang == 'nl' %}Onderbouwd{% else %}Substantiated{% endif %}

    {% if lang == 'nl' %}Een feit heeft een bron. Een mening mag je altijd geven, maar maak duidelijk wat feit is en wat mening.{% else %}A fact has a source. You are always free to give your opinion, but make clear what is fact and what is opinion.{% endif %}

  2. R2

    {% if lang == 'nl' %}Over het idee, niet de persoon{% else %}About the idea, not the person{% endif %}

    {% if lang == 'nl' %}Bekritiseer argumenten, geen mensen. Geen persoonlijke aanvallen, beledigingen of aannames over iemands bedoelingen.{% else %}Criticise arguments, not people. No personal attacks, insults or assumptions about someone's intentions.{% endif %}

  3. R3

    {% if lang == 'nl' %}Concreet{% else %}Concrete{% endif %}

    {% if lang == 'nl' %}Maak je punt zo specifiek mogelijk: een voorbeeld, een cijfer, een voorstel. Liever één helder argument dan tien vage.{% else %}Make your point as specific as possible: an example, a figure, a proposal. One clear argument beats ten vague ones.{% endif %}

  4. R4

    {% if lang == 'nl' %}Bij het onderwerp{% else %}On topic{% endif %}

    {% if lang == 'nl' %}Reageer op de vraag van het gesprek. Heb je een ander onderwerp? Start dan een nieuw gesprek.{% else %}Respond to the question of the conversation. Have a different topic? Then start a new conversation.{% endif %}

  5. R5

    {% if lang == 'nl' %}Eén account per persoon{% else %}One account per person{% endif %}

    {% if lang == 'nl' %}Iedereen spreekt met één stem. Meerdere accounts per persoon zijn niet toegestaan, ook niet onder een ander pseudoniem.{% else %}Everyone speaks with one voice. More than one account per person is not allowed, not even under another pseudonym.{% endif %}

{% if lang == 'nl' %}Moderators kunnen berichten die deze spelregels overtreden bewerken of verwijderen, en een gesprek sluiten.{% else %}Moderators can edit or remove posts that break these ground rules, and close a conversation.{% endif %}
