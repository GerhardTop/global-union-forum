Zo kom je bij verwijderen

Verwijderen begint op het vraagstuk zelf

Je opent een vraagstuk zoals altijd: via het menu Vraagstukken, of via een link in het dashboard (het vraagstuk-label bij een melding, of "Recente vraagstukken"). Op de pagina van dat vraagstuk vind je als admin het menu Beheer.
